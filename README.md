# RPGLE Free Format

Training material for a 3-day course on **RPG Fully Free Format** for new RPG developers.

Only Fully Free Format RPG is in scope. Each chapter is a separate markdown file, meant to be walked through and discussed with the students one at a time. The approach is example driven: every concept is explained together with a short, runnable code sample.
