# RPGLE Free Format

A guide to **RPG Fully Free Format**, for developers new to IBM i or to RPGLE.

Only Fully Free Format RPG is in scope. Each chapter is a separate markdown file, meant to be read one topic at a time. The approach is example driven: every concept is explained together with a short, runnable code sample.
