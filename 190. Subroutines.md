# Subroutines

A subroutine is a named block of code inside a program, that can be executed from multiple places without repeating the same statements. Subroutines were the traditional way to structure RPG code, before procedures (see next chapter) were introduced.

A subroutine has no parameters and no return value: it always works with the fields already declared in the program.


## BEGSR / ENDSR

A subroutine is declared with `begsr`, followed by a name, and ends with `endsr`.

```
   begsr calcTotal;
      wTotal = wPrice * wQty;
   endsr;
```

## EXSR

`exsr` executes (calls) a subroutine.

```
   dcl-s wPrice packed(7:2) inz(10);
   dcl-s wQty   int(5)      inz(3);
   dcl-s wTotal packed(9:2);

   exsr calcTotal;

   dsply wTotal;                 // 30.00

   begsr calcTotal;
      wTotal = wPrice * wQty;
   endsr;
```

## LEAVESR

`leavesr` immediately ends the subroutine and returns control to the statement right after the `exsr` that called it.

```
   begsr calcTotal;
      if wQty <= 0;
         wTotal = 0;
         leavesr;
      endif;
      wTotal = wPrice * wQty;
   endsr;
```


## Subroutines vs procedures

Subroutines are still fully supported in Fully Free Format RPG, but have two important limitations compared to procedures:

- A subroutine cannot receive parameters, it can only use fields that are already declared in the program.
- A subroutine cannot return a value directly.

The next chapter covers procedures, which do support parameters and return values.
