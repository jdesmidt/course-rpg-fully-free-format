# Data queues

A data queue (`*DTAQ`) is a fast, simple message queue: one job sends a piece of data onto the queue, another job (or the same job, later) receives it, in first-in-first-out order by default. It needs no locking and no journal, which makes it a common way for jobs to signal each other or hand over small amounts of data.


## Sending and receiving : QSNDDTAQ / QRCVDTAQ

```
   dcl-pr sndDtaq extpgm('QSNDDTAQ');
      qname  char(10) const;
      qlib   char(10) const;
      dtaLen packed(5:0) const;
      dta    char(256) const;
   end-pr;

   dcl-pr rcvDtaq extpgm('QRCVDTAQ');
      qname  char(10) const;
      qlib   char(10) const;
      dtaLen packed(5:0) const;
      dta    char(256);
      wait   packed(5:0) const;
   end-pr;
```

```

   dcl-s wMessage char(256);

   sndDtaq('MYQUEUE' : 'MYLIB' : 11 : 'Hello world');

   rcvDtaq('MYQUEUE' : 'MYLIB' : 256 : wMessage : 30);   // wait up to 30 seconds
   dsply wMessage;
```

- `qname`/`qlib` identify the data queue, the queue itself is created once, outside RPG, with the CL command `CRTDTAQ`.
- On `QSNDDTAQ`, `dtaLen` is the length of the data actually being sent, `dta` is that data.
- On `QRCVDTAQ`, `dtaLen` is the maximum length to receive into `dta`, and `wait` is how long (in seconds) to wait for a message if the queue is currently empty: `0` does not wait at all, `-1` waits forever.
- Because the queue only ever holds data, not a described record format, everything sent to it usually needs to be built up first (for example in a data structure), exactly the same way as for the IFS/C-runtime APIs in the Calling programs and API's chapter.


## IBM i Services alternative

Just like the classic system APIs seen elsewhere in this course, sending and receiving can also be done directly through embedded SQL, with `QSYS2.SEND_DATA_QUEUE` and `QSYS2.RECEIVE_DATA_QUEUE`, without needing the prototypes above. IBM keeps adding more of these SQL-based alternatives to older APIs, it is worth checking the IBM i Services documentation before writing a new prototype by hand.
