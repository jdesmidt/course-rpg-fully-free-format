# Arrays

An array is a stand alone field that holds multiple values of the same type, using the `dim` keyword to specify the number of elements.

```
   dcl-s wMonth char(9) dim(12);
```

## Initializing an array

`inz` gives every element of the array the same starting value, it cannot give each element a different one.

```
   dcl-s wScore packed(3:0) dim(5) inz(0);   // all 5 elements start at 0
```

To fill an array with different values per element in one statement instead of assigning every index one by one, assign it directly from `%list(...)` (see `for-each`, further below, and the Built-in functions chapter).

```
   dcl-s wMonth char(9) dim(12);

   wMonth = %list('January':'February':'March':'April':'May':'June':
                   'July':'August':'September':'October':'November':'December');
```

## Using an array

Elements are addressed with the field name, followed by the index between parentheses. The first element has index 1.

```
   dcl-s wMonth char(9) dim(12);

   wMonth(1)  = 'January';
   wMonth(2)  = 'February';
   wMonth(3)  = 'March';

   dsply wMonth(1);              // shows 'January'
```

- The index must be between 1 and the number of elements defined with `dim`.
- Arrays declared this way are static: the number of elements is fixed at compile time.

## for-each

`for-each` walks through every element of an array directly, without needing a loop counter or knowing how many elements there are.

```
   dcl-s wMonth char(9) dim(12);
   dcl-s wName  char(9);

   wMonth(1) = 'January';
   wMonth(2) = 'February';

   for-each wName in wMonth;
      dsply wName;
   endfor;
```

- The loop variable (`wName`) must be declared beforehand, with the same type as the array's elements.
- Unlike `for`, there is no index available inside the loop, only the value of the current element.

`for-each` also works directly on `%list(...)`, a quick way to list a few values without declaring an array for them at all.

```
   dcl-s wColor varchar(10);

   for-each wColor in %list('Red':'Blue':'Green':'Yellow');
      dsply wColor;
   endfor;
```

- `%list(value1:value2:...)` builds a temporary list of values, every value must be of the same type.
- `leave` and `iter` (see the Selections and iteration chapter) work inside a `for-each` loop exactly the same way as in a `for` loop.
- `for-each` also works directly on `%split(...)` and `%subarr(...)` (see the Built-in functions chapter), to walk through a string split into pieces, or through just part of an array.

## Sorting an array

`sorta` sorts every element of an array in place, in ascending order by default.

```
   dcl-s wMonth char(9) dim(3);

   wMonth(1) = 'March';
   wMonth(2) = 'January';
   wMonth(3) = 'February';

   sorta wMonth;

   dsply wMonth(1);              // 'February'
```

Add the `(a)` or `(d)` operation extender to choose the sort order explicitly.

```
   sorta(a) wMonth;               // ascending (this is the default)
   sorta(d) wMonth;               // descending
```
