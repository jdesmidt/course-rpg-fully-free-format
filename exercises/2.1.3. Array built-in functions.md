# 2.1.3 - Array built-in functions

**Topics practiced:** `%elem`, `%min`, `%max`, `%split`, `%subarr`, `%lookup`, `%list`.

**Description:** work with a CSV list of names, and a fixed array of months.


## Steps

1. Declare `wCsv` as `varchar(100)` with value `'Jurgen,Piet,An,Karel,Sofie'`.
2. Split it with `%split` and display every name using `for-each`.
3. Declare `wMonth`, `char(9) dim(12)`, and fill it with the 12 month names in one go using `%list()` (`inz` cannot give each element of an array a different value, it only sets one starting value shared by all elements).
4. Use `%elem` to loop over the whole array and display every month.
5. Use `%subarr` to take just Q2 (April, May, June) into a `dim(3)` array, and display it.
6. Use `%lookup` to find the position of `'June'` in `wMonth`.
7. Given `wA = 15` and `wB = 42`, display the smallest and the largest with `%min`/`%max`.


## Solution

```
**free

dcl-s wCsv   varchar(100) inz('Jurgen,Piet,An,Karel,Sofie');
dcl-s wName  varchar(20);
dcl-s wMonth char(9) dim(12);
dcl-s i      int(5);
dcl-s wQ2    char(9) dim(3);
dcl-s wA     int(5) inz(15);
dcl-s wB     int(5) inz(42);

wMonth = %list('January':'February':'March':'April':'May':'June':
    'July':'August':'September':'October':'November':'December');

for-each wName in %split(wCsv:',');
   dsply wName;
endfor;

for i = 1 to %elem(wMonth);
   dsply wMonth(i);
endfor;

wQ2 = %subarr(wMonth:4:3);

for-each wName in wQ2;
   dsply wName;
endfor;

dsply %lookup('June':wMonth);         // 6

dsply %min(wA:wB);                    // 15
dsply %max(wA:wB);                    // 42

*inlr = *on;
```

- `%list(value1:value2:...)` can be assigned straight to a whole array in one statement, exactly like it can be looped over directly with `for-each` (see the Arrays chapter), this is the way to fill an array with different values per element without assigning every index one by one.
- `%subarr(array:start:num)` can also be assigned to, to write a slice back into part of a bigger array.
- `%lookupge`/`%lookupgt`/`%lookuple`/`%lookuplt` need an `ascend`/`descend` array, an exact-match `%lookup` does not.
