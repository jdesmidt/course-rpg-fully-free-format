# 1.4.4 - Sorting an array

**Topics practiced:** `sorta`, `sorta(a)`, `sorta(d)`.

**Description:** sort the month array from exercise 1.4.3 alphabetically, ascending and descending.


## Steps

1. Reuse the filled `wMonth` array from exercise 1.4.3.
2. Sort it with a plain `sorta`, and display the first element.
3. Sort it again with `sorta(d)`, and display the first element, compare with the previous result.
4. Sort it once more with `sorta(a)`, and confirm it gives the same result as the plain `sorta`.


## Solution

```
**free

dcl-s wMonth char(9) dim(12);

wMonth(1)  = 'January';
wMonth(2)  = 'February';
wMonth(3)  = 'March';
wMonth(4)  = 'April';
wMonth(5)  = 'May';
wMonth(6)  = 'June';
wMonth(7)  = 'July';
wMonth(8)  = 'August';
wMonth(9)  = 'September';
wMonth(10) = 'October';
wMonth(11) = 'November';
wMonth(12) = 'December';

sorta wMonth;
dsply wMonth(1);              // 'April', first alphabetically

sorta(d) wMonth;
dsply wMonth(1);              // 'September', last alphabetically

sorta(a) wMonth;
dsply wMonth(1);              // 'April' again, (a) is the default

*inlr = *on;
```
