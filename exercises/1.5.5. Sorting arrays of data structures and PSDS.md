# 1.5.5 - Sorting arrays of data structures, and PSDS

**Topics practiced:** `sorta` on an array of data structures, `%fields()`, the Program Status Data Structure.

**Description:** sort the employee array from exercise 1.5.4 by salary, then look up the current program's name through the PSDS.


## Steps

1. Reuse the `wEmployee` array from exercise 1.5.4.
2. Sort it on `salary`, descending, with `sorta`.
3. Display the employees in order, highest paid first.
4. Sort it again, this time on `name` ascending as the primary key, using `%fields()`.
5. Declare a `psds` data structure with at least `program` (`pos(1)`) and `*status`, and display the program name.


## Solution

```
**free

dcl-ds wEmployee dim(3) qualified;
   name   char(20);
   salary packed(9:2);
end-ds;

wEmployee(1).name   = 'Jurgen';
wEmployee(1).salary = 3500.00;
wEmployee(2).name   = 'Piet';
wEmployee(2).salary = 3200.00;
wEmployee(3).name   = 'An';
wEmployee(3).salary = 4000.00;

sorta(d) wEmployee(*).salary;

dcl-s i int(5);
for i = 1 to %elem(wEmployee);
   dsply wEmployee(i).name;
endfor;

sorta wEmployee %fields(name);

dcl-ds wPgmInfo psds qualified;
   program char(10) pos(1);
   status  *status;
end-ds;

dsply wPgmInfo.program;

*inlr = *on;
```
