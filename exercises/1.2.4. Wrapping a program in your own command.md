# 1.2.4 - Wrapping a program in your own command

**Topics practiced:** `time(*hms)`/`timsep`, `%time`, `inz(*sys)`, `snd-msg *status`, creating a source physical file, a command (`*CMD`) source member, `CRTCMD`.

**Description:** write a program `NOW` that shows the current time at the bottom of the screen, then turn it into your own command, so it can be run just by typing `NOW` on any command line.


## Steps

### The program

1. Create a source member (or stream file) `NOW`.
2. Declare a `time(*hms) timsep(':')` field, and set it to `%time()`.
3. Replace that separate assignment: instead of setting the field with `%time()`, initialize it directly on the declaration with `inz(*sys)`, so it already holds the current time as soon as the program starts, no separate assignment statement is needed.
4. Build a message `'It''s now ' + %char(...)` (`%char` on this field gives `HH:MM:SS`, separated by colons).
5. Send it as a status message with `snd-msg *status`, so it shows at the bottom of the screen (see exercise 1.1.2) instead of scrolling into the joblog.
6. Compile it with `CRTBNDRPG`.

### The command

A command is a separate object (`*CMD`), it does not contain any logic itself, it only describes how the command can be called, and which program actually runs when it is. Its source is not RPG, but a small language of its own (`CMD`/`PARM`/...), stored in its own kind of source member.

7. Create a source physical file to hold command source, if you don't already have one: `CRTSRCPF FILE(MYLIB/QCMDSRC)`.
8. Add a new member `NOW` to `QCMDSRC`, of source type `CMD`.
9. Since this command needs no parameters, its entire source is one single line:
   ```
                CMD        PROMPT('Display the current time')
   ```
10. Compile it with `CRTCMD`, pointing `PGM` at the `NOW` program you compiled in step 6.
11. From any command line, type `NOW` and press Enter, the status message from your program should appear at the bottom of the screen.


## Solution

Program, member `NOW`:
```
**free

dcl-s wNowTime time(*hms) timsep(':') inz(*sys);
dcl-s wMessage varchar(52);

wMessage = 'It''s now ' + %char(wNowTime);

snd-msg *status wMessage;

*inlr = *on;
```

```
CRTBNDRPG PGM(MYLIB/NOW) SRCFILE(MYLIB/QRPGLESRC) SRCMBR(NOW)
```

Command source, member `NOW` in `QCMDSRC`:
```
             CMD        PROMPT('Display the current time')
```

```
CRTSRCPF FILE(MYLIB/QCMDSRC)

CRTCMD CMD(MYLIB/NOW) PGM(MYLIB/NOW) SRCFILE(MYLIB/QCMDSRC) SRCMBR(NOW)
```

Try it:
```
NOW
```

- `inz(*sys)` replaces the earlier `wNowTime = %time();` assignment entirely, initializing a field can take the place of a separate calculation statement whenever the starting value is all that is needed.
- `timsep(':')` is what makes `%char()` produce colons (`14:30:00`), without it `*hms` would not use that separator, exactly as shown for dates and times in the Fields chapter.
- `CRTSRCPF FILE(MYLIB/QCMDSRC)` only needs to be done once per library, further commands can add more members to the same file.
- The single `CMD PROMPT('...')` line is the smallest possible, valid command source: no parameters, just a description shown when the command is prompted with F4.
- `CRTCMD`'s `PGM` parameter is what links the command to the program that actually runs, the command source itself never names a program.
