# 1.2.3 - Eval, eval(h), evalr and compound assignment

**Topics practiced:** `eval` (implicit), `eval(h)`, `evalr`, `+=` `-=` `*=` `/=`.

**Description:** see the difference between a plain assignment, a rounded one, and a right-justified one.


## Steps

1. Declare `wResult` as `packed(5:1)`, assign it `10.16` with a plain assignment, then `dsply` it.
2. Assign the same value again with `eval(h)`, and `dsply` it, compare the two results.
3. Declare `wCode` as `char(5)`, assign it `'AB'` with a plain assignment, then with `evalr`, and `dsply` both.
4. Declare a counter field, and use `+=`, `-=`, `*=` and `/=` to change it step by step, displaying it after each one.


## Solution

```
**free

dcl-s wResult  packed(5:1);
dcl-s wCode    char(5);
dcl-s wCounter int(5) inz(10);

wResult = 10.16;
dsply wResult;               // 10.1  (truncated)

eval(h) wResult = 10.16;
dsply wResult;               // 10.2  (rounded)

wCode = 'AB';
dsply wCode;                 // 'AB   '

evalr wCode = 'AB';
dsply wCode;                 // '   AB'

wCounter += 5;
dsply wCounter;               // 15

wCounter -= 3;
dsply wCounter;               // 12

wCounter *= 2;
dsply wCounter;               // 24

wCounter /= 4;
dsply wCounter;               // 6

*inlr = *on;
```
