# 1.5.2 - Template and likeds

**Topics practiced:** `template`, `likeds`.

**Description:** define one shared address layout, and reuse it for a home and a work address.


## Steps

1. Declare a `template` data structure `t_address`, qualified, with `street`, `city`, `zip`.
2. Declare `wHomeAddress` and `wWorkAddress`, both `likeds(t_address)` (no need to also code `qualified`, `likeds` already implies it).
3. Fill in different values for each, and `dsply` both cities.
4. Try to assign a value directly to `t_address.city` and notice this does not make sense, a template holds no data of its own.


## Solution

```
**free

dcl-ds t_address qualified template;
   street char(30);
   city   char(20);
   zip    char(10);
end-ds;

dcl-ds wHomeAddress likeds(t_address);
dcl-ds wWorkAddress likeds(t_address);

wHomeAddress.city = 'Brussels';
wWorkAddress.city = 'Antwerp';

dsply wHomeAddress.city;
dsply wWorkAddress.city;

*inlr = *on;
```

- `t_address` reserves no storage, it only exists so `wHomeAddress` and `wWorkAddress` can reuse its layout with `likeds`.
- `likeds` always makes the resulting data structure qualified on its own, coding `qualified` alongside it is redundant, the compiler rejects the combination.
