# 1.2.1 - Constants and control options

**Topics practiced:** `dcl-c`, `ctl-opt` (`copyright`, `text`, `decedit`, `datfmt`/`timfmt`).

**Description:** declare a few constants, and set up a program header with `ctl-opt`.


## Steps

1. Add a `ctl-opt` with `text(...)`, `copyright(...)`, `decedit('0.')` and `datfmt(*iso) timfmt(*iso)`.
2. Declare a constant `MAX_ATTEMPTS` with the value `3`, once with the `const` keyword, once without.
3. Declare a constant `VAT_RATE` with the value `21.00`.
4. `dsply` both constants.


## Solution

```
**free

ctl-opt text('Exercise 1.2.1');
ctl-opt copyright('(c) my company');
ctl-opt decedit('0.');
ctl-opt datfmt(*iso) timfmt(*iso);

dcl-c MAX_ATTEMPTS const(3);
dcl-c VAT_RATE     21.00;

dsply MAX_ATTEMPTS;
dsply VAT_RATE;

*inlr = *on;
```

- `dcl-c MAX_ATTEMPTS const(3);` and `dcl-c MAX_ATTEMPTS 3;` mean exactly the same thing, `const` is optional.
