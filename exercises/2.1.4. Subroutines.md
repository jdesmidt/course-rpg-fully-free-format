# 2.1.4 - Subroutines

**Topics practiced:** `begsr`/`endsr`, `exsr`, `leavesr`.

**Description:** calculate an order total in a subroutine, and skip the calculation through `leavesr` when the quantity is invalid.


## Steps

1. Declare `wPrice` (packed 7:2), `wQty` (int 5) and `wTotal` (packed 9:2).
2. Write a subroutine `calcTotal` that sets `wTotal = wPrice * wQty`.
3. Call it with `exsr`, for `wPrice = 10` and `wQty = 3`, and display `wTotal`.
4. Change the subroutine so that when `wQty <= 0`, it sets `wTotal` to 0 and leaves immediately with `leavesr`, without executing the multiplication.
5. Call it again with `wQty = -1`, and confirm `wTotal` is 0.


## Solution

```
**free

dcl-s wPrice packed(7:2);
dcl-s wQty   int(5);
dcl-s wTotal packed(9:2);

wPrice = 10;
wQty   = 3;
exsr calcTotal;
dsply wTotal;                  // 30.00

wPrice = 10;
wQty   = -1;
exsr calcTotal;
dsply wTotal;                  // 0.00

*inlr = *on;

begsr calcTotal;
   if wQty <= 0;
      wTotal = 0;
      leavesr;
   endif;
   wTotal = wPrice * wQty;
endsr;
```

- A subroutine has no parameters, it always works on fields that are already declared in the program, that is the main difference with the procedures covered next.
