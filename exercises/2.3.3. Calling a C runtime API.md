# 2.3.3 - Calling a C runtime API

**Topics practiced:** `extproc`, `ctl-opt bnddir('QC2LE')`, calling `sleep` from the C runtime library.

**Description:** pause a program for a few seconds using the C runtime's `sleep` function, called directly from RPG.


## Steps

1. Add `ctl-opt bnddir('QC2LE');`, the C runtime is bound in through this binding directory.
2. Declare a prototype `sleep`, returning `uns(10)`, with `extproc('sleep')`, taking one `uns(10) value` parameter.
3. Display a message, call `sleep(3)`, then display a second message, so the 3 second pause is visible between the two.


## Solution

```
**free
ctl-opt bnddir('QC2LE');

dcl-pr sleep uns(10) extproc('sleep');
   seconds uns(10) value;
end-pr;

dsply 'starting...';
sleep(3);
dsply 'done after 3 seconds';

*inlr = *on;
```

- `extproc` is the counterpart of `extpgm`, but for a real bound procedure call instead of a program `CALL`, this is why `sleep` can have a return value just like a normal procedure.
- `value` lets a literal (`3`) be passed directly, exactly as with an internal procedure.
