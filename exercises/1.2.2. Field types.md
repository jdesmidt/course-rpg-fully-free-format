# 1.2.2 - Field types

**Topics practiced:** `zoned`, `packed`, `ind`, `char`, `varchar`, `pointer`, `int`, `uns`, `date`, `time`, `timestamp`, `inz`.

**Description:** declare one field of every type covered so far, initialize it, and display it.


## Steps

1. Declare one field of each of these types: `zoned`, `packed`, `ind`, `char`, `varchar`, `pointer`, `int`, `uns`, `date`, `time`, `timestamp`.
2. Give every field (except the pointer) a sensible `inz` value.
3. `dsply` each of them.
4. For the pointer, use `%addr()` to point it at one of the other fields, then `dsply %size()` of that same field.


## Solution

```
**free

dcl-s wAmount    zoned(7:2)  inz(99.95);
dcl-s wQty       packed(5:0) inz(10);
dcl-s wActive    ind         inz(*on);
dcl-s wCode      char(5)     inz('ABCDE');
dcl-s wName      varchar(20) inz('Jurgen Desmidt');
dcl-s wPtr       pointer;
dcl-s wCount     int(10)     inz(0);
dcl-s wSequence  uns(10)     inz(1);
dcl-s wOrderDte  date(*iso)  inz(*sys);
dcl-s wStartTim  time(*iso)  inz(*sys);
dcl-s wCreatTst  timestamp   inz(*sys);

dsply wAmount;
dsply wQty;
dsply wActive;
dsply wCode;
dsply wName;
dsply wCount;
dsply wSequence;
dsply wOrderDte;
dsply wStartTim;
dsply wCreatTst;

wPtr = %addr(wAmount);
dsply %size(wAmount);

*inlr = *on;
```
