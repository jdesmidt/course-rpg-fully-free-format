# 2.4.4 - Printing with QPRINT

**Topics practiced:** program-described printer file, `QPRINT`.

**Description:** print a short report of two lines, using the ready-made `QPRINT` printer file.


## Steps

1. Declare `dcl-f qprint printer(132);`, a program-described printer file, 132 characters per line.
2. Declare a data structure `printLine`, `len(132)`, with a `char(50)` subfield `text`.
3. Set `text` to a title line, and `write` it to `qprint`.
4. Set `text` to a second line, and `write` it again.
5. After compiling and running, check the spooled file with `WRKSPLF` (or `WRKOUTQ`).


## Solution

```
**free

dcl-f qprint printer(132);

dcl-ds printLine len(132);
   text char(50);
end-ds;

printLine.text = 'Monthly order report';
write qprint printLine;

printLine.text = 'Generated on ' + %char(%date());
write qprint printLine;

*inlr = *on;
```

- `printer(132)` needs no external DDS source, `QPRINT` is a printer file IBM i already provides.
- Each `write` produces one printed line, in the exact layout of `printLine`.
