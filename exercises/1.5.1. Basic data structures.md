# 1.5.1 - Basic data structures

**Topics practiced:** `dcl-ds`/`end-ds`, unqualified vs `qualified`.

**Description:** declare an address as a data structure, once unqualified, once qualified.


## Steps

1. Declare `wAddress` (unqualified) with subfields `street`, `city`, `zip`.
2. Assign values to `street` and `city` directly (no data structure name needed), and `dsply` `city`.
3. Now declare a second data structure `wDeliveryAddress`, `qualified`, with the same subfields.
4. Assign and display its `city` subfield, this time through `wDeliveryAddress.city`.
5. Discuss: why would `qualified` be required if both data structures were declared in the same program?


## Solution

```
**free

dcl-ds wAddress;
   street char(30);
   city   char(20);
   zip    char(10);
end-ds;

street = 'Main street 1';
city   = 'Brussels';

dsply city;

dcl-ds wDeliveryAddress qualified;
   street char(30);
   city   char(20);
   zip    char(10);
end-ds;

wDeliveryAddress.street = 'Industry lane 42';
wDeliveryAddress.city   = 'Antwerp';

dsply wDeliveryAddress.city;

*inlr = *on;
```

- Without `qualified`, `street` and `city` become plain, global fields, if `wDeliveryAddress` were also unqualified, its `street`/`city` subfields would clash with `wAddress`'s.
