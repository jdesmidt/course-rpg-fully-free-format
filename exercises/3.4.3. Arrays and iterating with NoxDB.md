# 3.4.3 - Arrays and iterating with NoxDB

**Topics practiced:** `json_newArray`, `json_arrayPush`, `json_copy_clone`, `json_setIterator`/`json_forEach`.

**Description:** build an array of order-quantity objects from an RPG array, then read it back by iterating over it.


## Steps

1. Add `ctl-opt bnddir('JSONPARSER');` and `/copy qcpysrc,jsonparser`.
2. Fill an RPG array `wQuantities`, `int(5) dim(3)`, with `10`, `25`, `5`.
3. Create an empty array node `pBatchOrders` with `json_newArray()`.
4. Loop over `wQuantities`: for each one, create a scratch object `pOrder` with `json_newObject()`, set its `quantity` with `json_setNum`, push it into `pBatchOrders` with `json_arrayPush(... : json_copy_clone)`, then `json_delete(pOrder)`.
5. Iterate back over `pBatchOrders` with `json_setIterator`/`json_forEach`, reading `quantity` from each element with `json_getNum`, and displaying it.
6. Release `pBatchOrders` with `json_delete`.


## Solution

```
**free
ctl-opt bnddir('JSONPARSER');

/copy qcpysrc,jsonparser

dcl-s wQuantities   int(5) dim(3);
dcl-s pBatchOrders  pointer;
dcl-s pOrder        pointer;
dcl-s i             int(5);
dcl-s wOrderQuantity int(5);
dcl-s orderIterator likeds(json_iterator);

wQuantities(1) = 10;
wQuantities(2) = 25;
wQuantities(3) = 5;

pBatchOrders = json_newArray();

for i = 1 to %elem(wQuantities);
   pOrder = json_newObject();
   json_setNum(pOrder : 'quantity' : wQuantities(i));

   json_arrayPush(pBatchOrders : pOrder : json_copy_clone);
   json_delete(pOrder);
endfor;

orderIterator = json_setIterator(pBatchOrders);

dow json_forEach(orderIterator);
   wOrderQuantity = json_getNum(orderIterator.this : 'quantity');
   dsply wOrderQuantity;
enddo;

json_delete(pBatchOrders);

*inlr = *on;
```

- `json_copy_clone` copies `pOrder`'s current content into the array instead of linking to `pOrder` itself, this is exactly what allows `pOrder` to be rebuilt and deleted again on every pass of the loop.
- `json_setIterator`/`json_forEach` walk the children of a node one at a time, `orderIterator.this` is a pointer to whichever element is current.
