# 1.4.2 - Dow, dou, for and leave/iter

**Topics practiced:** `dow`/`enddo`, `dou`/`enddo`, `for`/`endfor` (`to` and `downto`), `leave`, `iter`.

**Description:** print the same countdown three different ways, then skip and stop early in a `for` loop.


## Steps

1. Using `dow`, print the numbers 1 to 5.
2. Using `dou`, print the numbers 5 down to 1.
3. Using `for ... downto`, print the numbers 10, 8, 6, 4, 2 (step 2).
4. Using `for i = 1 to 10`, skip the number 3 with `iter`, and stop entirely once you reach 7 with `leave`.


## Solution

```
**free

dcl-s wCount int(5);
dcl-s i      int(5);

wCount = 1;
dow wCount <= 5;
   dsply wCount;
   wCount += 1;
enddo;

wCount = 5;
dou wCount = 0;
   dsply wCount;
   wCount -= 1;
enddo;

for i = 10 downto 2 by 2;
   dsply i;
endfor;

for i = 1 to 10;
   if i = 3;
      iter;                    // skip the rest of this pass
   endif;
   if i = 7;
      leave;                   // stop the loop entirely
   endif;
   dsply i;
endfor;

*inlr = *on;
```
