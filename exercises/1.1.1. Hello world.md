# 1.1.1 - Hello world

**Topics practiced:** `**FREE`, `dcl-s`, `dsply`, `*inlr`, compiling with `CRTBNDRPG`.

**Description:** write, compile and run the smallest useful RPG program.


## Steps

1. Create a source member (or stream file) `HELLO`.
2. Start it with `**FREE` on the first line.
3. Declare a character field holding your own name.
4. Use `dsply` to show `'Hello, <name>!'`.
5. Set `*inlr = *on;` at the end.
6. Compile it with `CRTBNDRPG`, and call it.


## Solution

```
**free

dcl-s wName varchar(30) inz('Jurgen');

dsply ('Hello, ' + %trim(wName) + '!');

*inlr = *on;
```

```
CRTBNDRPG PGM(MYLIB/HELLO) SRCFILE(MYLIB/QRPGLESRC) SRCMBR(HELLO)
CALL MYLIB/HELLO
```
