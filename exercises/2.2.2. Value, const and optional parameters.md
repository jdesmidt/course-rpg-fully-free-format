# 2.2.2 - Value, const and optional parameters

**Topics practiced:** `value`, `const`, `options(*nopass)`, `options(*omit)`.

**Description:** write a discount procedure where the discount rate is optional, and a greeting procedure where a prefix can explicitly be left out.


## Steps

1. Declare `ctl-opt dftactgrp(*no) actgrp(*caller);`.
2. Write `calcDiscount`, returning `packed(7:2)`, with `pAmount` (`const`) and an optional `pRate` (`const options(*nopass)`).
3. Inside, use `%parms`/`%parmnum` to check whether `pRate` was passed, if not, return `pAmount` unchanged.
4. Call `calcDiscount` once with only `pAmount`, once with both parameters.
5. Write `addTax`, returning `packed(9:2)`, with `pAmount` as `value` and `pRate` as `const`, and call it with two literals directly (no variables).
6. Write `showMessage`, with `pText` (`const`) and `pPrefix` (`const options(*nopass : *omit)`, so it can either be left out of the call entirely, or explicitly passed as `*omit`), check `%addr(pPrefix) = *null` to decide whether to show the prefix.
7. Call `showMessage` three times: with only text, with a prefix, and explicitly passing `*omit`.


## Solution

```
**free
ctl-opt dftactgrp(*no) actgrp(*caller);

dsply calcDiscount(100);              // 100.00, no discount
dsply calcDiscount(100 : 10);         // 90.00

dsply addTax(100 : 21);               // 121.00, literals allowed thanks to value/const

showMessage('Done');                  // 'Done'
showMessage('Done' : 'INFO');         // 'INFO: Done'
showMessage('Done' : *omit);          // 'Done', explicitly no prefix

dcl-proc calcDiscount;
   dcl-pi calcDiscount packed(7:2);
      pAmount packed(7:2) const;
      pRate   packed(5:2) const options(*nopass);
   end-pi;

   if %parms < %parmnum(pRate);
      return pAmount;
   endif;

   return pAmount - (pAmount * pRate / 100);
end-proc;

dcl-proc addTax;
   dcl-pi addTax packed(9:2);
      pAmount packed(7:2) value;
      pRate   packed(5:2) const;
   end-pi;

   return pAmount + (pAmount * pRate / 100);
end-proc;

dcl-proc showMessage;
   dcl-pi showMessage;
      pText   varchar(50) const;
      pPrefix varchar(10) const options(*nopass : *omit);
   end-pi;

   if %addr(pPrefix) = *null;
      dsply pText;
   else;
      dsply (pPrefix + ': ' + pText);
   endif;
end-proc;

*inlr = *on;
```

- `value` gives the procedure its own private copy, so it can never change the caller's variable, and it accepts literals/expressions.
- `const` is read-only but still passed by reference, `options(*omit)` only makes sense together with `const` or `value`.
- `options(*omit)` on its own only allows the caller to explicitly pass `*omit`, it does not allow leaving the argument out of the call entirely, that still needs `options(*nopass)` too, which is why `pPrefix` combines both.
