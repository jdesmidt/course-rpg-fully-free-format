# 2.3.2 - Executing a command with QCMDEXC

**Topics practiced:** `QCMDEXC`, calling an IBM-supplied API exactly like any other `*PGM`.

**Description:** delete a temporary file in `QTEMP` from within RPG, using the `QCMDEXC` API.


## Steps

1. Declare a prototype `ExecuteCommand` with `extpgm('QCMDEXC')`, taking a `char(3000) const` command and a `packed(15:5) const` length.
2. Build the command text `'DLTF FILE(QTEMP/MYFILE)'` in a variable, and its exact trimmed length in another.
3. Call `ExecuteCommand`, passing the command and its length.
4. Call it again using `callp(e)` instead, so a failure (the file did not exist) does not end the program.


## Solution

```
**free

dcl-pr ExecuteCommand extpgm('QCMDEXC');
   command char(3000) const;
   length  packed(15:5) const;
end-pr;

dcl-s wCommand    varchar(256);
dcl-s wCommandLen packed(15:5);

wCommand    = 'DLTF FILE(QTEMP/MYFILE)';
wCommandLen = %len(%trim(wCommand));

ExecuteCommand(wCommand : wCommandLen);

callp(e) ExecuteCommand(wCommand : wCommandLen);
if %error();
   dsply 'command failed, file probably did not exist';
endif;

*inlr = *on;
```

- The length parameter must be the exact length of the trimmed command text, not the declared size of the variable.
- Most of the thousands of APIs IBM i ships are, just like `QCMDEXC`, plain `*PGM` objects in library `QSYS`, prototyped and called the exact same way.
