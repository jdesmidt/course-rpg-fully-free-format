# 1.5.3 - Pos and overlay

**Topics practiced:** `pos`, `overlay`.

**Description:** split an 8-character date string into year, month and day, without copying anything.


## Steps

1. Declare a data structure with a `char(8)` subfield holding `'20260724'`.
2. Add three more subfields, `wYear` (4 chars), `wMonth` (2 chars), `wDay` (2 chars), each `overlay`-ing the right part of the first subfield.
3. `dsply` all three, without ever assigning them directly.
4. Change the original 8-character value, and notice the 3 overlaid subfields change along with it.


## Solution

```
**free

dcl-ds wDate;
   wDateChar char(8) inz('20260724');
   wYear     char(4) overlay(wDateChar);
   wMonth    char(2) overlay(wDateChar : 5);
   wDay      char(2) overlay(wDateChar : 7);
end-ds;

dsply wYear;                  // '2026'
dsply wMonth;                 // '07'
dsply wDay;                   // '24'

wDateChar = '20271231';
dsply wYear;                  // '2027', changed along with wDateChar
dsply wDay;                   // '31'

*inlr = *on;
```
