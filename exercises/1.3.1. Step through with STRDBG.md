# 1.3.1 - Step through with STRDBG

**Topics practiced:** `STRDBG`, `UPDPROD`, F6 (breakpoint), F10 (step), F11 (display).

**Description:** debug the field-types program from exercise 1.2.2, one statement at a time.


## Steps

1. Compile the program from exercise 1.2.2 (or a similar one with a few field assignments).
2. `STRDBG PGM(MYLIB/yourpgm) UPDPROD(*YES);`
3. Put the cursor on the first executable line, press **F6** to set a breakpoint there.
4. `CALL MYLIB/yourpgm`, the debugger takes over at the breakpoint.
5. Press **F10** repeatedly to step through, one statement at a time.
6. After a few steps, put the cursor on a field and press **F11** to see its current value.
7. Press **F3** to end the debug session.


## Solution

```
STRDBG PGM(MYLIB/FIELDTYPES) UPDPROD(*YES);
-- F6 on the first statement
CALL MYLIB/FIELDTYPES
-- F10, F10, F10, ...
-- put the cursor on wAmount, press F11
```

- There is no RPG code to write for this exercise, the "solution" is the sequence of debugger commands above.
