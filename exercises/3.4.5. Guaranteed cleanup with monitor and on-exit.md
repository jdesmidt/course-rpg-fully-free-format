# 3.4.5 - Guaranteed cleanup with monitor and on-exit

**Topics practiced:** combining `monitor`/`on-error` with `on-exit`, so `json_delete`/`json_sqlDisconnect` always run, even after an error.

**Description:** write a procedure that looks up one customer by SQL, guaranteed to clean up its NoxDB node and SQL connection no matter how it ends.


## Steps

1. Add `ctl-opt bnddir('JSONPARSER');`, `ctl-opt dftactgrp(*no) actgrp(*caller);`, and `/copy qcpysrc,jsonparser`.
2. Write a procedure `findCustomer`, taking a `const` `companyId`, returning an indicator.
3. Inside a `monitor` block, run `json_sqlResultSet` for that company, `json_locate` the first row, and `return *on;` if found.
4. In `on-error`, `return *off;`.
5. After `endmon`, add `on-exit`, releasing the node with `json_delete` and the connection with `json_sqlDisconnect`, this must run whichever `return` above was reached.
6. Call the procedure once with a company id that exists, and once with one that doesn't, and display both results.


## Solution

```
**free
ctl-opt bnddir('JSONPARSER');
ctl-opt dftactgrp(*no) actgrp(*caller);

/copy qcpysrc,jsonparser

dsply findCustomer('CD001');            // *on
dsply findCustomer('DOES-NOT-EXIST');   // *off

*inlr = *on;

dcl-proc findCustomer;
   dcl-pi findCustomer ind;
      companyId varchar(64) const;
   end-pi;

   dcl-s pCustomer pointer;

   monitor;
      pCustomer = json_sqlResultSet('select * from customers where cucompanyid = ''' + companyId + '''');
      pCustomer = json_locate(pCustomer : '[0]');

      if pCustomer = *null;
         return *off;
      endif;

      return *on;
   on-error;
      return *off;
   endmon;

   on-exit;
      json_delete(pCustomer);
      json_sqlDisconnect();
end-proc;
```

- Whichever `return` is reached, the normal one, the "not found" one, or the one inside `on-error`, `on-exit` still runs afterward, so `json_delete`/`json_sqlDisconnect` always happen exactly once.
- `json_delete(*null)` is harmless, this is what makes the pattern safe even when `pCustomer` was never assigned, for example if `json_sqlResultSet` itself failed.
