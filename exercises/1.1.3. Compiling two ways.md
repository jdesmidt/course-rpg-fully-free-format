# 1.1.3 - Compiling two ways

**Topics practiced:** `CRTRPGMOD` + `CRTPGM` (two steps) vs `CRTBNDRPG` (one step).

**Description:** compile the same source both ways, and compare.


## Steps

1. Reuse (or write again) the `HELLO` program from exercise 1.1.1.
2. Compile it in two separate steps: first into a module, then bind that module into a program.
3. Delete the program object, and compile the exact same source again, in one single command this time.
4. Discuss: when would the two-step way be preferred over the one-step way?


## Solution

```
-- two steps
CRTRPGMOD MODULE(MYLIB/HELLO) SRCFILE(MYLIB/QRPGLESRC) SRCMBR(HELLO)
CRTPGM PGM(MYLIB/HELLO) MODULE(MYLIB/HELLO)

-- one step
DLTPGM PGM(MYLIB/HELLO)
CRTBNDRPG PGM(MYLIB/HELLO) SRCFILE(MYLIB/QRPGLESRC) SRCMBR(HELLO)
```

- The two-step way is needed as soon as a program is built from more than one module, or when modules need to be bound into a service program instead of directly into a program (see the ILE concepts chapter, day 3).
