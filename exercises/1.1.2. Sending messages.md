# 1.1.2 - Sending messages

**Topics practiced:** `dsply` vs `snd-msg`, `*escape`, `*status`.

**Description:** send different kinds of messages, and see where each one shows up.


## Steps

1. `dsply` a message to the screen.
2. `snd-msg` a plain informational message, then check the joblog (`DSPJOBLOG`) for it.
3. `snd-msg *escape` a message, and notice the program ends immediately after.
4. `snd-msg *status` a message, and notice it appears at the bottom of the screen instead of the joblog.


## Solution

```
**free

dsply 'Step 1 : hello from dsply';

snd-msg 'Step 2 : a plain informational message';

snd-msg *status 'Step 4 : shown at the bottom of the screen';

snd-msg *escape 'Step 3 : this ends the program right here';

dsply 'This line is never reached';

*inlr = *on;
```

- Reordering `*status` before `*escape` above is deliberate: once `*escape` runs, the program stops, so anything coded after it would never execute.
