# 2.5.1 - Singleton select and exists check

**Topics practiced:** `exec sql`, host variables, `set option`, singleton `select ... into`, checking existence via `sqlcode`.

**Description:** look up one employee's name by id, then check whether another employee id exists without reading any of its columns.


## Steps

1. Create the `employees` table (SQL below), and insert a few rows.
2. Add `exec sql set option naming = *sys, commit = *none, datfmt = *iso;` as the very first SQL statement.
3. Declare `wEmpId`, `wFirstName`, `wLastName` and fetch the employee's name with a singleton `select ... into`, using `fetch first 1 row only`.
4. Declare an indicator `wExist`, and check whether a second employee id exists by selecting the constant `1` into it, instead of `select count(*)`.
5. Display `'Employee exists'` or `'Employee not found'` based on `wExist`.


## Solution

### The table

```sql
CREATE TABLE employees (
   empId     DEC(7, 0) NOT NULL,
   firstName CHAR(20),
   lastName  CHAR(20),
   PRIMARY KEY (empId)
);

INSERT INTO employees VALUES (1234, 'Jurgen', 'Desmidt');
INSERT INTO employees VALUES (1235, 'Piet', 'Janssens');
INSERT INTO employees VALUES (1236, 'An', 'Peeters');
```

### The program

```
**free
exec sql set option naming = *sys, commit = *none, datfmt = *iso;

dcl-s wEmpId     packed(7:0) inz(1234);
dcl-s wFirstName char(20);
dcl-s wLastName  char(20);
dcl-s wOtherId   packed(7:0) inz(9999);
dcl-s wExist     ind inz(*off);

exec sql
   select firstName, lastName
     into :wFirstName, :wLastName
     from employees
    where empId = :wEmpId
    fetch first 1 row only;

dsply (%trim(wFirstName) + ' ' + %trim(wLastName));

exec sql
   select 1
     into :wExist
     from employees
    where empId = :wOtherId
    fetch first 1 row only;

if wExist;
   dsply 'Employee exists';
else;
   dsply 'Employee not found';
endif;

*inlr = *on;
```

- `select 1 into :wExist` lets the database stop looking as soon as one matching row is found, cheaper than `select count(*)`.
- `fetch first 1 row only` avoids an error if the query could technically return more than one row.
- `wOtherId` is set to `9999`, which was never inserted, so this displays `'Employee not found'`, change it to `1235` (or any other id that was inserted) to see the other branch.
