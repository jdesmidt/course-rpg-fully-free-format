# 3.3.2 - Generating JSON with YAJL

**Topics practiced:** `yajl_genOpen`/`yajl_genClose`, `yajl_beginObj`/`yajl_endObj`, `yajl_beginArray`/`yajl_endArray`, `yajl_addChar`/`yajl_addNum`/`yajl_addBool`.

**Description:** generate a small JSON document with a success flag and a list of invoices, using YAJL.


## Steps

1. Add `ctl-opt decedit('0.');`, JSON needs a leading digit before the decimal point.
2. Declare an `invoiceRec` template (`invoice`, `date`, `name`, `amount`), and `invoices likeds(invoiceRec) dim(3)`, filled with 3 sample invoices.
3. `yajl_genOpen(*on);`, then `yajl_beginObj();`.
4. Add `'success'` (bool, `*on`) and `'errmsg'` (char, `''`) key/value pairs.
5. `yajl_beginArray('list');`, loop over `invoices`, adding one object per invoice, then `yajl_endArray();` and `yajl_endObj();`.
6. Copy the result into a variable with `yajl_copyBuf()`, display it, then `yajl_genClose();`.


## Solution

```
**free
ctl-opt decedit('0.');

dcl-ds invoiceRec qualified template;
   invoice varchar(10);
   date    varchar(10);
   name    varchar(50);
   amount  packed(9:2);
end-ds;

dcl-ds invoices likeds(invoiceRec) dim(3);
dcl-s  i    int(5);
dcl-s  json varchar(4096);

invoices(1).invoice = '70689';
invoices(1).date    = '03/01/2014';
invoices(1).name    = 'SCOTT KLEMENT';
invoices(1).amount  = 14.80;

invoices(2).invoice = '70690';
invoices(2).date    = '03/02/2014';
invoices(2).name    = 'JURGEN DESMIDT';
invoices(2).amount  = 22.50;

invoices(3).invoice = '70691';
invoices(3).date    = '03/03/2014';
invoices(3).name    = 'PIET JANSSENS';
invoices(3).amount  = 9.99;

yajl_genOpen(*on);
yajl_beginObj();

yajl_addBool('success' : *on);
yajl_addChar('errmsg'  : '');

yajl_beginArray('list');

for i = 1 to %elem(invoices);
   yajl_beginObj();
   yajl_addChar('invoice' : invoices(i).invoice);
   yajl_addChar('date'    : invoices(i).date);
   yajl_addChar('name'    : invoices(i).name);
   yajl_addNum ('amount'  : %char(invoices(i).amount));
   yajl_endObj();
endfor;

yajl_endArray();
yajl_endObj();

json = yajl_copyBuf();
dsply json;

yajl_genClose();

*inlr = *on;
```

- Every `yajl_begin...`/`yajl_end...` pair must balance, exactly like matching brackets in the JSON itself.
- `yajl_addNum` still takes a character value, `%char()` is needed to convert `invoices(i).amount` first.
