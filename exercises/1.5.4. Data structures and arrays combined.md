# 1.5.4 - Data structures and arrays combined

**Topics practiced:** a data structure as an array, a data structure containing an array field, nesting a `dcl-ds` inside another.

**Description:** build an employee list (array of data structures), and an order with repeating lines (array field inside one data structure).


## Steps

1. Declare `wEmployee`, qualified, `dim(3)`, with `name` and `salary` subfields, fill in 3 employees.
2. Declare `wOrder`, qualified (not an array), with `orderNr`, and a `lineDesc`/`lineQty` pair of subfields that are themselves arrays (`dim(5)`).
3. Fill in 2 order lines, and display them.
4. Declare a third data structure `wDelivery`, with a nested `dcl-ds lines dim(10);` directly inside it (no separate template), and fill in one line.


## Solution

```
**free

dcl-ds wEmployee dim(3) qualified;
   name   char(20);
   salary packed(9:2);
end-ds;

wEmployee(1).name   = 'Jurgen';
wEmployee(1).salary = 3500.00;
wEmployee(2).name   = 'Piet';
wEmployee(2).salary = 3200.00;
wEmployee(3).name   = 'An';
wEmployee(3).salary = 4000.00;

dcl-ds wOrder qualified;
   orderNr  packed(7:0);
   lineDesc char(30) dim(5);
   lineQty  int(5)   dim(5);
end-ds;

wOrder.orderNr     = 1001;
wOrder.lineDesc(1) = 'Keyboard';
wOrder.lineQty(1)  = 2;
wOrder.lineDesc(2) = 'Mouse';
wOrder.lineQty(2)  = 1;

dsply wOrder.lineDesc(1);
dsply wOrder.lineDesc(2);

dcl-ds wDelivery qualified;
   deliveryId varchar(64);
   dcl-ds lines dim(10);
      itemId   varchar(64);
      quantity zoned(9:0);
   end-ds;
end-ds;

wDelivery.deliveryId  = 'DLV-001';
wDelivery.lines(1).itemId   = 'ITEM-001';
wDelivery.lines(1).quantity = 5;

dsply wDelivery.lines(1).itemId;

*inlr = *on;
```
