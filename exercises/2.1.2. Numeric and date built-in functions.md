# 2.1.2 - Numeric and date built-in functions

**Topics practiced:** `%dec`, `%int`, `%char`, `%editc`, `%editw`, `%date`, `%diff`, `%days`, `%months`, `%parms`, `%addr`, `%size`.

**Description:** convert an incoming character amount into a packed field, format it for display, and calculate a due date a number of months later.


## Steps

1. Declare `wAmountTxt` as `char(10)` with value `'  1250.75'`, and convert it into `wAmount`, a `packed(9:2)` field, using `%dec`.
2. Display `wAmount` formatted with `%editc`, edit code `'1'`.
3. Display `wAmount` formatted with `%editw`, mask `'   ,   .  '`.
4. Convert `wAmount` back into text with `%char`, and display it.
5. Declare `wOrderDte` as `date(*iso)`, set it to today with `%date()`, then calculate `wDueDte` as 2 months later using `%months`.
6. Display the number of days between `wOrderDte` and `wDueDte` using `%diff`.
7. Declare a procedure interface with 2 required and 1 optional parameter, and use `%parms`/`%addr`/`%size` to report how many parameters were passed and how many bytes the first one occupies.


## Solution

```
**free

dcl-s wAmountTxt char(10) inz('  1250.75');
dcl-s wAmount    packed(9:2);
dcl-s wAmountChr varchar(15);

wAmount = %dec(wAmountTxt:9:2);

dsply %editc(wAmount:'1');            // '1,250.75'
dsply %editw(wAmount:'   ,   .  ');   // '  1,250.75'

wAmountChr = %char(wAmount);
dsply wAmountChr;                     // '1250.75'

dcl-s wOrderDte date(*iso);
dcl-s wDueDte   date(*iso);

wOrderDte = %date();
wDueDte   = wOrderDte + %months(2);

dsply %diff(wDueDte:wOrderDte:*days);

dcl-pr checkParms extpgm;
   pRequired1 char(10);
   pRequired2 char(10);
   pOptional  char(10) options(*nopass);
end-pr;

dcl-pi *n;
   pRequired1 char(10);
   pRequired2 char(10);
   pOptional  char(10) options(*nopass);
end-pi;

dsply %parms;                         // number of parameters actually passed
dsply %size(pRequired1);              // 10
dsply %int(%addr(pRequired1) <> *null); // 1, the parameter always has an address

*inlr = *on;
```

- `%dec(value:length:decimals)` also accepts a `varchar` or numeric source value, not only fixed `char`.
- `%parms`/`%parmnum` are covered again, together with `options(*nopass)`, in the Internal procedures exercises.
