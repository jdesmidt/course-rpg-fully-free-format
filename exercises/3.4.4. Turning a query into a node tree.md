# 3.4.4 - Turning a query into a node tree

**Topics practiced:** `json_sqlResultSet`, `json_locate`, format options (`json_TOTALROWS`, `json_CAMEL_CASE`), `json_sqlDisconnect`.

**Description:** run a query directly into a NoxDB node tree, without a cursor or a matching data structure, once as a plain array and once with the total row count included.


## Steps

1. Add `ctl-opt bnddir('JSONPARSER');` and `/copy qcpysrc,jsonparser`.
2. Build a `select * from customers where cucity = :city` style statement (substitute the literal city value directly into the string).
3. Run it with `json_sqlResultSet(statement)`, and pick out the first row with `json_locate(... : '[0]')`.
4. Read `cucompanyname` from that row with `json_getStr`, and display it.
5. Run the same statement again, this time with `json_TOTALROWS` as the `formatOptions` parameter, read `totalRows` with `json_getInt`, then `json_locate(... : 'rows[0]')` for the first row.
6. Release both node trees with `json_delete`, and the connection with `json_sqlDisconnect`.


## Solution

```
**free
ctl-opt bnddir('JSONPARSER');

/copy qcpysrc,jsonparser

dcl-s wCity          varchar(20) inz('Antwerp');
dcl-s wSqlStatement  varchar(500);
dcl-s pCustomers     pointer;
dcl-s pFirstCustomer pointer;
dcl-s wCompanyName   varchar(128);
dcl-s wTotalRows     int(10);

wSqlStatement = 'select * from customers where cucity = ''' + %trim(wCity) + '''';

pCustomers     = json_sqlResultSet(wSqlStatement);
pFirstCustomer = json_locate(pCustomers : '[0]');

wCompanyName = json_getStr(pFirstCustomer : 'cucompanyname');
dsply wCompanyName;

json_delete(pCustomers);

pCustomers   = json_sqlResultSet(wSqlStatement : 1 : json_ALLROWS : json_TOTALROWS);
wTotalRows   = json_getInt(pCustomers : 'totalRows');
pFirstCustomer = json_locate(pCustomers : 'rows[0]');

dsply wTotalRows;

json_delete(pCustomers);
json_sqlDisconnect();

*inlr = *on;
```

- Without any `formatOptions`, `json_sqlResultSet` returns a plain array, one object per row, `json_locate(... : '[0]')` reaches the first one directly.
- `json_TOTALROWS` wraps the array in an object instead, moving the rows under a `rows` property alongside `totalRows`, this is why the path changes to `'rows[0]'`.
- `json_sqlDisconnect()` releases the SQL connection opened by `json_sqlResultSet`, it is only needed once, even after several calls.
