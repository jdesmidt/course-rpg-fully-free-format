# 2.5.2 - A static cursor

**Topics practiced:** `declare cursor for`, `open`, `fetch next`, `sqlcode`, `close`.

**Description:** list every customer in one city, one row at a time, using a static cursor.


## Steps

1. Declare `wCity`, `wCustNr`, `wCustName`.
2. `exec sql declare custCur cursor for select custNr, custName from customers where city = :wCity;`.
3. `open` the cursor, then `fetch next` into `wCustNr`/`wCustName`.
4. Loop with `dow sqlcode = 0;`, displaying the customer name and fetching the next row each time.
5. `close` the cursor after the loop.


## Solution

```
**free

dcl-s wCity     char(20) inz('Antwerp');
dcl-s wCustNr   packed(7:0);
dcl-s wCustName char(30);

exec sql declare custCur cursor for
   select custNr, custName
     from customers
    where city = :wCity;

exec sql open custCur;

exec sql fetch next from custCur into :wCustNr, :wCustName;

dow sqlcode = 0;
   dsply wCustName;
   exec sql fetch next from custCur into :wCustNr, :wCustName;
enddo;

exec sql close custCur;

*inlr = *on;
```

- This cursor's SQL text is fixed at compile time, this is what makes it "static": no `prepare` step is needed, unlike the dynamic cursor in the next exercise.
- `sqlcode = 0` means a row was successfully fetched, once there are no more rows it becomes `100`, ending the loop.
