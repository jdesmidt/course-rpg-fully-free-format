# 2.5.2 - A static cursor

**Topics practiced:** `declare cursor for`, `open`, `fetch next`, `sqlcode`, `close`.

**Description:** list every supplier in one city, one row at a time, using a static cursor.


## Steps

1. Create the `suppliers` table (SQL below), and insert a few rows. The `CUSTOMERS` file from exercise 2.4.1 is not used here, it has no `city` column, `suppliers` is a separate, SQL-created table for this and the next two exercises.
2. Declare `wCity`, `wSupplierId`, `wSupplierName`.
3. `exec sql declare supCur cursor for select supplierId, supplierName from suppliers where city = :wCity;`.
4. `open` the cursor, then `fetch next` into `wSupplierId`/`wSupplierName`.
5. Loop with `dow sqlcode = 0;`, displaying the supplier name and fetching the next row each time.
6. `close` the cursor after the loop.


## Solution

### The table

```sql
CREATE TABLE suppliers (
   supplierId   DEC(7, 0) GENERATED BY DEFAULT AS IDENTITY (START WITH 2000) NOT NULL,
   supplierName CHAR(30),
   city         CHAR(20),
   PRIMARY KEY (supplierId)
);

INSERT INTO suppliers (supplierId, supplierName, city) VALUES (1001, 'Acme Supplies', 'Antwerp');
INSERT INTO suppliers (supplierId, supplierName, city) VALUES (1002, 'Beta Parts', 'Antwerp');
INSERT INTO suppliers (supplierId, supplierName, city) VALUES (1003, 'Gamma Trading', 'Brussels');
```

### The program

```
**free

dcl-s wCity          char(20) inz('Antwerp');
dcl-s wSupplierId    packed(7:0);
dcl-s wSupplierName  char(30);

exec sql declare supCur cursor for
   select supplierId, supplierName
     from suppliers
    where city = :wCity;

exec sql open supCur;

exec sql fetch next from supCur into :wSupplierId, :wSupplierName;

dow sqlcode = 0;
   dsply wSupplierName;
   exec sql fetch next from supCur into :wSupplierId, :wSupplierName;
enddo;

exec sql close supCur;

*inlr = *on;
```

- This cursor's SQL text is fixed at compile time, this is what makes it "static": no `prepare` step is needed, unlike the dynamic cursor in the next exercise.
- `sqlcode = 0` means a row was successfully fetched, once there are no more rows it becomes `100`, ending the loop.
