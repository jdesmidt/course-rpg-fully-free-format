# 1.3.3 - Debug a batch job

**Topics practiced:** `STRSRVJOB`, `STRDBG`, `ENDDBG`, `ENDSRVJOB`.

**Description:** debug a job that is not your own interactive session, using a second session to service it.


## Steps

1. Submit a program to batch, held, so it doesn't start running immediately: `SBMJOB CMD(CALL MYLIB/YOURPGM) JOB(MYJOB) JOBQ(QBATCH) HOLD(*YES);`
2. In a second (interactive) session, find the job's number with `WRKJOBQ QBATCH;`.
3. `STRSRVJOB JOB(number/user/MYJOB);` to attach to it.
4. `STRDBG PGM(MYLIB/YOURPGM) UPDPROD(*YES);`, set a breakpoint with **F6**.
5. `RLSJOB JOB(number/user/MYJOB);`, the job starts running, and stops at your breakpoint.
6. Step through as usual, then `ENDDBG;` followed by `ENDSRVJOB;`.


## Solution

```
SBMJOB CMD(CALL MYLIB/YOURPGM) JOB(MYJOB) JOBQ(QBATCH) HOLD(*YES);

WRKJOBQ QBATCH;                            -- note the job number

STRSRVJOB JOB(123456/JDESMIDT/MYJOB);
STRDBG PGM(MYLIB/YOURPGM) UPDPROD(*YES);   -- set a breakpoint with F6

RLSJOB JOB(123456/JDESMIDT/MYJOB);

-- step through with F10 / F11 / F12 as usual

ENDDBG;
ENDSRVJOB;
```
