# 2.4.3 - Write, update and delete

**Topics practiced:** `write`, `update`, `delete`.

**Description:** add a new order, ship it, then remove it again.


## Steps

1. Declare `dcl-f orders keyed usage(*update : *output : *delete);`, and a qualified record format data structure `orderRec` with `extname('ORDERS')`.
2. Fill in `custNr` and `orderDate`, and `write` the record.
3. `chain` back on the same key, change `status` to `'SHIPPED'`, and `update` the record.
4. `chain` on the same key again, and `delete` it.


## Solution

```
**free

dcl-f orders keyed usage(*update : *output : *delete);

dcl-ds orderRec extname('ORDERS') qualified;
end-ds;

orderRec.custNr    = 1001;
orderRec.orderDate = %date();
write orders orderRec;                  // add a new record

chain 1001 orders;
orderRec.status = 'SHIPPED';
update orders orderRec;                 // change the record just read

chain 1001 orders;
delete orders;                          // remove the record just read

*inlr = *on;
```

- `usage(*update : *output : *delete)` is needed for all three operations, `*delete` alone would already imply `*input`/`*update`, but `*output` (needed for `write`) has to be added explicitly.
- `update` and `delete` both act on the record that was last read (by `chain`, here), not on whatever values happen to be in the fields.
