# 2.2.3 - %passed and %omitted

**Topics practiced:** `%passed`, `%omitted`, as the modern alternative to `%parms`/`%parmnum` and `%addr(parameter) = *null`.

**Description:** rewrite the two procedures from exercise 2.2.2 using `%passed` and `%omitted`, which read more directly.


## Steps

1. Declare `ctl-opt dftactgrp(*no) actgrp(*caller);`.
2. Rewrite `calcDiscount`, replacing the `%parms < %parmnum(pRate)` check with `not %passed(pRate)`.
3. Rewrite `showMessage`, replacing `%addr(pPrefix) = *null` with `%omitted(pPrefix)`.
4. Call both procedures with the same combinations as in 2.2.2, and confirm the results are identical.
5. Note: `%passed`/`%omitted` require IBM i 7.4 (via PTF) or later, on an older release the 2.2.2 style is still needed.


## Solution

```
**free
ctl-opt dftactgrp(*no) actgrp(*caller);

dsply calcDiscount(100);              // 100.00, no discount
dsply calcDiscount(100 : 10);         // 90.00

showMessage('Done');                  // 'Done'
showMessage('Done' : 'INFO');         // 'INFO: Done'
showMessage('Done' : *omit);          // 'Done', explicitly no prefix

dcl-proc calcDiscount;
   dcl-pi calcDiscount packed(7:2);
      pAmount packed(7:2) const;
      pRate   packed(5:2) const options(*nopass);
   end-pi;

   if not %passed(pRate);
      return pAmount;
   endif;

   return pAmount - (pAmount * pRate / 100);
end-proc;

dcl-proc showMessage;
   dcl-pi showMessage;
      pText   varchar(50) const;
      pPrefix varchar(10) const options(*omit);
   end-pi;

   if %omitted(pPrefix);
      dsply pText;
   else;
      dsply (pPrefix + ': ' + pText);
   endif;
end-proc;

*inlr = *on;
```

- `%passed` answers "was an argument supplied at all", `%omitted` answers "was `*omit` explicitly passed", the two are often combined when a parameter is both optional and omittable.
