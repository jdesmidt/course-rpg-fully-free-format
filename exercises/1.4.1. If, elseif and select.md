# 1.4.1 - If, elseif and select

**Topics practiced:** comparison/logical operators, `if`/`elseif`/`else`, `select`/`when`/`other`.

**Description:** classify a numeric grade, once with `if`/`elseif`, once with `select`/`when`.


## Steps

1. Declare a field `wGrade` (packed), and a field `wActionCode` (char(2)).
2. With `if`/`elseif`/`else`, display `'A'`, `'B'`, `'C'` or `'F'` depending on `wGrade` (`>=90`, `>=80`, `>=70`, else).
3. With `select`/`when`/`other`, display an action description for `wActionCode` (`'01'`=New, `'02'`=Update, `'04'`=Delete, anything else=Unknown).
4. Combine both types of conditions with `and`/`or` in a single `if`, once with, once without extra parentheses.


## Solution

```
**free

dcl-s wGrade      packed(3:0) inz(85);
dcl-s wActionCode char(2)     inz('02');

if wGrade >= 90;
   dsply 'A';
elseif wGrade >= 80;
   dsply 'B';
elseif wGrade >= 70;
   dsply 'C';
else;
   dsply 'F';
endif;

select;
   when wActionCode = '01';
      dsply 'New';
   when wActionCode = '02';
      dsply 'Update';
   when wActionCode = '04';
      dsply 'Delete';
   other;
      dsply 'Unknown action code';
endsl;

if wGrade >= 70 and wActionCode <> '04';
   dsply 'Still enrolled and passing';
endif;

if (wGrade >= 70) and (wActionCode <> '04');
   dsply 'Same result, with parentheses';
endif;

*inlr = *on;
```
