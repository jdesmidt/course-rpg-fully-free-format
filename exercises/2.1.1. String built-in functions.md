# 2.1.1 - String built-in functions

**Topics practiced:** `%subst`, `%trim`/`%triml`/`%trimr`, `%scan`, `%replace`, `%scanrpl`, `%len`.

**Description:** clean up and rework a messy name field using string BIFs.


## Steps

1. Declare `wName` as `char(30)`, filled with `'  Jurgen Desmidt   '` (leading and trailing blanks on purpose).
2. Display the trimmed value, and its length after trimming.
3. Use `%scan` to find the position where `'Desmidt'` starts in the trimmed value.
4. Use `%subst` to display only the first name (everything before the space).
5. Use `%replace` to change `'Desmidt'` into `'Peeters'`.
6. Use `%scanrpl` to replace every space in the trimmed value with an underscore.


## Solution

```
**free

dcl-s wName char(30) inz('  Jurgen Desmidt   ');
dcl-s wTrim varchar(30);
dcl-s wPos  int(5);

wTrim = %trim(wName);
dsply wTrim;                          // 'Jurgen Desmidt'
dsply %len(wTrim);                    // 14

wPos = %scan('Desmidt':wTrim);
dsply wPos;                           // 8

dsply %subst(wTrim:1:%scan(' ':wTrim) - 1);   // 'Jurgen'

dsply %replace('Peeters':wTrim:wPos);         // 'Jurgen Peeters'

dsply %scanrpl(' ':'_':wTrim);                // 'Jurgen_Desmidt'

*inlr = *on;
```

- `%triml`/`%trimr` remove only leading, resp. trailing blanks, useful when the other side needs to stay intact.
