# 1.4.3 - Arrays and for-each

**Topics practiced:** `dim`, `inz`, indexing an array, `for-each`.

**Description:** build a 12-element month array, and walk through it two different ways.


## Steps

1. Declare `wMonth`, `char(9)`, `dim(12)`.
2. Declare a second array `wScore`, `packed(3:0)`, `dim(5)`, and initialize every element to `0` in one go with `inz`.
3. Fill in all 12 months of `wMonth` by assigning `wMonth(1)` through `wMonth(12)` individually.
4. Walk through `wMonth` with a `for` loop and an index, then again with `for-each`, and compare the two.


## Solution

```
**free

dcl-s wMonth char(9) dim(12);
dcl-s wScore packed(3:0) dim(5) inz(0);
dcl-s wName  char(9);
dcl-s i      int(5);

wMonth(1)  = 'January';
wMonth(2)  = 'February';
wMonth(3)  = 'March';
wMonth(4)  = 'April';
wMonth(5)  = 'May';
wMonth(6)  = 'June';
wMonth(7)  = 'July';
wMonth(8)  = 'August';
wMonth(9)  = 'September';
wMonth(10) = 'October';
wMonth(11) = 'November';
wMonth(12) = 'December';

for i = 1 to %elem(wMonth);
   dsply wMonth(i);
endfor;

for-each wName in wMonth;
   dsply wName;
endfor;

*inlr = *on;
```
