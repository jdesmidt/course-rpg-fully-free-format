# 1.4.5 - Building a date message

**Topics practiced:** `if`/`elseif`/`else`, `select`/`when`/`other`.

**Description:** display `Today is 27th of July.`, working out the day suffix (`st`/`nd`/`rd`/`th`) with `if`/`elseif`, and the month name with `select`.


## Steps

1. Declare `wDay`, `inz(27)`, and `wMonth`, `inz(7)`, both numeric.
2. With `if`/`elseif`/`else`, work out the 2-character suffix into `wSuffix`: `11`, `12` and `13` are always `'th'` (check this first, using `or`), otherwise `1`/`21`/`31` → `'st'`, `2`/`22` → `'nd'`, `3`/`23` → `'rd'`, anything else → `'th'`.
3. With `select`/`when`/`other`, turn `wMonth` (`1`-`12`) into its name, into `wMonthName`.
4. Compose the full message, and `dsply` it: `'Today is ' + wDay + wSuffix + ' of ' + wMonthName + '.'`.
5. Change `wDay` to `11`, `21` and `2`, rerun, and check the suffix is still correct every time.


## Solution

```
**free

dcl-s wDay        int(5)      inz(27);
dcl-s wMonth      int(5)      inz(7);
dcl-s wSuffix     char(2);
dcl-s wMonthName  varchar(9);
dcl-s wMessage    varchar(50);

if wDay = 11 or wDay = 12 or wDay = 13;
   wSuffix = 'th';                     // 11th, 12th, 13th are the exception
elseif wDay = 1 or wDay = 21 or wDay = 31;
   wSuffix = 'st';
elseif wDay = 2 or wDay = 22;
   wSuffix = 'nd';
elseif wDay = 3 or wDay = 23;
   wSuffix = 'rd';
else;
   wSuffix = 'th';
endif;

select;
   when wMonth = 1;
      wMonthName = 'January';
   when wMonth = 2;
      wMonthName = 'February';
   when wMonth = 3;
      wMonthName = 'March';
   when wMonth = 4;
      wMonthName = 'April';
   when wMonth = 5;
      wMonthName = 'May';
   when wMonth = 6;
      wMonthName = 'June';
   when wMonth = 7;
      wMonthName = 'July';
   when wMonth = 8;
      wMonthName = 'August';
   when wMonth = 9;
      wMonthName = 'September';
   when wMonth = 10;
      wMonthName = 'October';
   when wMonth = 11;
      wMonthName = 'November';
   when wMonth = 12;
      wMonthName = 'December';
   other;
      wMonthName = 'Unknown';
endsl;

wMessage = 'Today is ' + %char(wDay) + wSuffix + ' of ' + wMonthName + '.';

dsply wMessage;                        // 'Today is 27th of July.'

*inlr = *on;
```

- `11`, `12` and `13` have to be checked first: since only the first matching `elseif` ever runs, testing `wDay = 1`/`21`/`31` before them would wrongly turn `11` into `'st'` instead of `'th'`.
- A calendar day only ever runs from `1` to `31`, which is exactly why listing every exact value (`1`, `21`, `31`, ...) works here, no remainder or division is needed to look at "the last digit".
