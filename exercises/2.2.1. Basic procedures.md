# 2.2.1 - Basic procedures

**Topics practiced:** `dcl-proc`/`end-proc`, `dcl-pi`, return values, `ctl-opt dftactgrp(*no) actgrp(*caller)`.

**Description:** turn the `calcTotal` subroutine from the previous exercise into a real procedure with parameters and a return value.


## Steps

1. Add `ctl-opt dftactgrp(*no) actgrp(*caller);` at the top, procedures require this.
2. Declare a procedure `calcTotal` that returns `packed(9:2)`, with two `const` parameters, `pPrice` (packed 7:2) and `pQty` (int 5).
3. Inside, `return pPrice * pQty;`.
4. Call it twice from the main line of code, with different values each time, directly inside `dsply`.
5. Compare this to the subroutine version: no global fields need to be set up before each call.


## Solution

```
**free
ctl-opt dftactgrp(*no) actgrp(*caller);

dsply calcTotal(10 : 3);           // 30.00
dsply calcTotal(25 : 2);           // 50.00

dcl-proc calcTotal;
   dcl-pi calcTotal packed(9:2);
      pPrice packed(7:2) const;
      pQty   int(5)      const;
   end-pi;

   return pPrice * pQty;
end-proc;

*inlr = *on;
```

- Every call can use a different `pPrice`/`pQty` without touching a single global field, unlike the subroutine version from exercise 2.1.4.
