# 2.4.2 - Setll, setgt and reade

**Topics practiced:** `setll`, `setgt`, `*start`, `read`/`%eof`, `reade`.

**Description:** list every order for one customer, then list every order in the whole file from the start.


## Steps

1. Create the `ORDERS` physical file (DDS below), keyed on `custNr` only (not unique), and insert a few rows: at least 2 for customer `1001`, and 1 for a different customer.
2. Declare `dcl-f orders keyed;`, with key field `custNr`.
3. `setll` on a customer number, then loop with `reade` on that same customer number until `%eof(orders)`, displaying the order date each time.
4. Now `setll *start orders;`, then loop with plain `read`/`%eof` until the end of the whole file, displaying every order date regardless of customer.
5. Explain in a comment why `reade` needs `setll` first, but the second loop does not need a key value at all.


## Solution

### The file

DDS source, member `ORDERS`:
```
     A          R ORDERREC
     A            CUSTNR         7S 0
     A            ORDERDATE      L   DATFMT(*ISO)
     A            STATUS        10A
     A          K CUSTNR
```

```
CRTPF FILE(MYLIB/ORDERS) SRCFILE(MYLIB/QDDSSRC) SRCMBR(ORDERS)
```

```sql
INSERT INTO MYLIB/ORDERS VALUES (1001, '2026-01-10', 'NEW');
INSERT INTO MYLIB/ORDERS VALUES (1001, '2026-01-15', 'NEW');
INSERT INTO MYLIB/ORDERS VALUES (1002, '2026-01-12', 'NEW');
```

### The program

```
**free

dcl-f orders keyed;

dcl-s wCustNr packed(7:0) inz(1001);

// only this customer's orders, in key sequence
setll wCustNr orders;
reade wCustNr orders;
dow not %eof(orders);
   dsply orderDate;
   reade wCustNr orders;
enddo;

// every order in the file, from the very beginning
setll *start orders;
read orders;
dow not %eof(orders);
   dsply orderDate;
   read orders;
enddo;

*inlr = *on;
```

- `setll custNr` positions at the first order for that customer, `reade custNr` then only keeps reading as long as the key still matches, `%eof` turns on as soon as it no longer does.
- `setll *start` positions at the very beginning of the file without needing a key value, this is the one form of `setll` that also works on a non-`keyed` file.
