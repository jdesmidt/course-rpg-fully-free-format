# 2.4.1 - Declaring a file and chain

**Topics practiced:** `dcl-f`, `usage`, `keyed`, `chain`, `%found`.

**Description:** look up one customer directly by key from a `CUSTOMERS` file.


## Steps

1. Declare `dcl-f customers keyed;` (default `usage` is `*input`, which is all a lookup needs).
2. Declare a numeric field `wCustNr`, set it to an existing customer number.
3. `chain` on `wCustNr` into `customers`.
4. Check `%found(customers)`, display the customer's name when found, otherwise display `'not found'`.
5. Repeat with a customer number that does not exist, and confirm the `not found` message.


## Solution

```
**free

dcl-f customers keyed;

dcl-s wCustNr packed(7:0) inz(1001);

chain wCustNr customers;

if %found(customers);
   dsply custName;
else;
   dsply 'not found';
endif;

*inlr = *on;
```

- `keyed` is required before `chain` can be used with an actual key value, without it the file can only be read sequentially.
- `%found(file)` must be checked right after `chain`, the fields of the record format only hold meaningful values when a record was actually found.
