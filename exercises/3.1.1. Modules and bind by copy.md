# 3.1.1 - Modules and bind by copy

**Topics practiced:** `nomain`, shared prototypes via `/copy`, `CRTRPGMOD`, `CRTPGM`.

**Description:** split a rounding procedure into its own module, and bind it directly into a calling program.


## Steps

1. In member `QCPYSRC(MATHUTIL_H)`, write a prototype `roundAmount`, returning `packed(9:2)`, with one `const` parameter `pAmount packed(9:4)`, using plain `extproc` (no name in parentheses).
2. In member `QRPGLESRC(MATHUTIL)`, add `ctl-opt nomain;`, `/copy qcpysrc,mathutil_h`, then implement `roundAmount` with `dcl-proc`/`dcl-pi *n`, returning `%dec(pAmount:9:2)`.
3. In member `QRPGLESRC(ORDER001)`, add `ctl-opt dftactgrp(*no) actgrp(*caller);`, `/copy` the same prototype member, call `roundAmount(12.3456)`, and display the result.
4. Compile both as modules with `CRTRPGMOD`, then bind them together with `CRTPGM MODULE(MYLIB/ORDER001 MYLIB/MATHUTIL)`.


## Solution

Prototype, `QCPYSRC(MATHUTIL_H)`:
```
dcl-pr roundAmount packed(9:2) extproc;
   pAmount packed(9:4) const;
end-pr;
```

Module, `QRPGLESRC(MATHUTIL)`:
```
**free
ctl-opt nomain;

/copy qcpysrc,mathutil_h

dcl-proc roundAmount;
   dcl-pi *n packed(9:2);
      pAmount packed(9:4) const;
   end-pi;

   return %dec(pAmount:9:2);         // rounds to 2 decimals
end-proc;
```

Calling program, `QRPGLESRC(ORDER001)`:
```
**free
ctl-opt dftactgrp(*no) actgrp(*caller);

/copy qcpysrc,mathutil_h

dcl-s wRounded packed(9:2);

wRounded = roundAmount(12.3456);

dsply wRounded;                      // 12.35

*inlr = *on;
```

Compile and bind:
```
CRTRPGMOD MODULE(MYLIB/ORDER001) SRCFILE(MYLIB/QRPGLESRC)
CRTRPGMOD MODULE(MYLIB/MATHUTIL) SRCFILE(MYLIB/QRPGLESRC)

CRTPGM PGM(MYLIB/ORDER001) MODULE(MYLIB/ORDER001 MYLIB/MATHUTIL)
```

- Both modules' compiled code is copied into `ORDER001` itself ("bind by copy"), if `MATHUTIL` changes later, `ORDER001` must be recreated to pick up the change.
- `/copy`'ing the same `MATHUTIL_H` member in both the module and the caller keeps the prototype and the real implementation in sync, even though they are compiled separately.
