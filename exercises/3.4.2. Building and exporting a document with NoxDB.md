# 3.4.2 - Building and exporting a document with NoxDB

**Topics practiced:** `json_newObject`, `json_setStr`, `json_asJsonText`, `json_writeJsonStmf`, `json_delete`.

**Description:** build a small order-journal object from scratch, export it both as text and to a file on the IFS.


## Steps

1. Add `ctl-opt bnddir('JSONPARSER');` and `/copy qcpysrc,jsonparser`.
2. Create an empty object node with `json_newObject()`.
3. Add fields `olcompanyid`, `olorderid`, `olactionid` (`'PLANNED'`) and `oltext` with `json_setStr`.
4. Convert the node to text with `json_asJsonText`, and display it.
5. Write the same node to `/tmp/journal.json` with `json_writeJsonStmf`, human-readable.
6. Release the node with `json_delete`.


## Solution

```
**free
ctl-opt bnddir('JSONPARSER');

/copy qcpysrc,jsonparser

dcl-s pJournal  pointer;
dcl-s wJsonText varchar(1000);
dcl-s wCompanyId varchar(10) inz('CD001');
dcl-s wOrderId   varchar(10) inz('ORD1234');
dcl-s wBatchId   int(10)     inz(42);

pJournal = json_newObject();
json_setStr(pJournal : 'olcompanyid' : wCompanyId);
json_setStr(pJournal : 'olorderid'   : wOrderId);
json_setStr(pJournal : 'olactionid'  : 'PLANNED');
json_setStr(pJournal : 'oltext'      : 'Order added to batch ' + %char(wBatchId));

wJsonText = json_asJsonText(pJournal);
dsply wJsonText;

json_writeJsonStmf(pJournal : '/tmp/journal.json' : 1208 : *on);

json_delete(pJournal);

*inlr = *on;
```

- `json_asJsonText` returns the node tree as a normal `varchar`, `json_writeJsonStmf` writes the same tree straight to the IFS, choosing `*on` for the last parameter makes the file human-readable instead of compact.
- `json_delete` must still be called even though nothing was parsed, `json_newObject()` also returns a node that needs releasing.
