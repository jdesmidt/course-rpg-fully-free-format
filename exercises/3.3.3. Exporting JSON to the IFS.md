# 3.3.3 - Exporting JSON to the IFS

**Topics practiced:** `yajl_copyBuf`, `yajl_saveBuf`.

**Description:** generate a tiny JSON document and save it directly to a file on the IFS, instead of just keeping it in a variable.


## Steps

1. `yajl_genOpen(*on);`, `yajl_beginObj();`, add one `'name'`/`'age'` pair, `yajl_endObj();`.
2. Save the buffer straight to `/home/jurgen/person.json` with `yajl_saveBuf`, passing a variable to receive any error message.
3. Display the error message variable, it should be blank when the save succeeded.
4. Also copy the same buffer into a variable with `yajl_copyBuf`, and display it, to compare both ways of getting the JSON out.
5. `yajl_genClose();`.


## Solution

```
**free
ctl-opt decedit('0.');

dcl-s json     varchar(1000);
dcl-s errormsg varchar(500);

yajl_genOpen(*on);
yajl_beginObj();

yajl_addChar('name' : 'Jurgen');
yajl_addNum ('age'  : '25');

yajl_endObj();

yajl_saveBuf('/home/jurgen/person.json' : errormsg);
dsply errormsg;                  // blank when the save succeeded

json = yajl_copyBuf();
dsply json;

yajl_genClose();

*inlr = *on;
```

- `yajl_saveBuf` and `yajl_copyBuf` can both be used on the same buffer, one writes straight to the IFS, the other returns the text into an RPG variable, whichever the situation needs.
- `yajl_writeStdOut` (not used here) is the third option, for writing the JSON directly to standard out, typically from a CGI or web service program.
