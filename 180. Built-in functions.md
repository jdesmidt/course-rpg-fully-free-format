# Built-in functions

Built-in functions (BIFs) are predefined functions provided by the RPG compiler. They always start with a percent sign `%`.


## Built-in functions based on field type

### %subst / %trim / %trimr / %scan / %replace / %len

```
   dcl-s wName char(20) inz('Jurgen Desmidt');

   dsply %subst(wName:1:6);            // 'Jurgen'
   dsply %trim(wName);                 // 'Jurgen Desmidt' without trailing blanks
   dsply %scan('Desmidt':wName);       // 8 -> position where 'Desmidt' starts
   dsply %replace('Piet':wName:1:6);   // 'Piet Desmidt'
   dsply %len(%trim(wName));           // 14
```

- `%subst(string:start:length)` extracts part of a string. It can also be used at the left of an assignment, to replace part of a string.
- `%trim(string)` removes leading and trailing blanks. `%triml` and `%trimr` only remove leading, resp. trailing blanks.
- `%scan(search:string:start)` returns the position where `search` was found in `string`, or `0` when not found. `start` is optional, and lets the search begin further into `string` instead of at the beginning.
- `%replace(new:string:start:length)` replaces part of `string`, starting at `start`, with `new`.
- `%len(string)` returns the length of a string.

### %scanrpl

`%replace` needs to know the exact position to replace, `%scanrpl` instead searches for a value and replaces every place it occurs, without needing a position.

```
   dcl-s wText varchar(50) inz('2026-07-22');

   dsply %scanrpl('-':'/':wText);      // '2026/07/22', every '-' replaced with '/'
```

- `%scanrpl(old:new:string)` returns `string` with every occurrence of `old` replaced by `new`.
- Optional start and end positions can be added to only replace occurrences within part of `string`.

### %dec / %int / %char

```
   dcl-s wAmount packed(7:2);
   dcl-s wText   varchar(10);

   wAmount = %dec('123.45':7:2); // convert text to a packed(7:2) value
   wText   = %char(wAmount);     // convert a numeric value to text
   dsply %int(wAmount);          // 123 (decimals truncated)
```

- `%dec(value:length:decimals)` converts a value into a packed number with the given length and number of decimals.
- `%int(value)` converts a value into an integer, truncating any decimals.
- `%char(value)` converts a numeric, date or time value into its character representation.

### %editc

A numeric field (`packed`, `zoned`, `int`, ...) only holds digits, it has no comma, no decimal point as such, and no way to hide a value of zero. `%editc(value:editcode)` formats a numeric value into readable text, using one of a fixed set of predefined edit codes.

```
   dcl-s wAmount packed(9:2) inz(1234.5);

   dsply %editc(wAmount:'1');            // '1,234.50'
```

Every edit code is a combination of three things: whether commas are inserted, whether a value of exactly zero is shown as blank instead of `.00`, and how a negative value is shown.

| Code | Comma | Zero shown as | Negative shown as |
| --- | --- | --- | --- |
| `1` | yes | `.00` | not shown (looks positive!) |
| `2` | yes | blank | not shown |
| `3` | no | `.00` | not shown |
| `4` | no | blank | not shown |
| `A` | yes | `.00` | `CR` |
| `B` | yes | blank | `CR` |
| `C` | no | `.00` | `CR` |
| `D` | no | blank | `CR` |
| `J` | yes | `.00` | trailing `-` |
| `K` | yes | blank | trailing `-` |
| `L` | no | `.00` | trailing `-` |
| `M` | no | blank | trailing `-` |

```
   dcl-s wAmount packed(9:2) inz(-1234.5);

   dsply %editc(wAmount:'1');            // '1,234.50'   <- looks positive, the sign is simply not shown!
   dsply %editc(wAmount:'J');            // '1,234.50-'
   dsply %editc(wAmount:'A');            // '1,234.50CR'
```

- Codes `1`-`4` never show a sign at all, only use them when the value can never be negative, or when losing the sign genuinely does not matter.
- There are a few more specialized edit codes beyond this table (for example one that formats a numeric field as a date), the IBM RPG reference has the full list.

### %editw

`%editw(value:editword)` also formats a numeric value as text, but instead of picking a predefined edit code, the exact layout is built by hand, as a mask.

```
   dcl-s wAmount packed(8:2) inz(123456.78);

   dsply %editw(wAmount:'   ,  , .  ');  // '123,45,6.78'
```

- In the mask, a blank marks where the next digit goes, any other character (here `,` and `.`) is copied to the output as-is, at that exact position. The mask above is `XXX,XX,X.XX` with every `X` replaced by an actual blank, one blank per digit of `wAmount`.
- `&` in the mask forces a real blank into the output, useful when a position needs to stay empty without being mistaken for "insert the next digit here".
- Unlike `%editc`, nothing happens automatically: to show a sign for a negative value, the mask itself must include a `-` (or `CR`) character where it should appear.

`%editc` is simpler for everyday formatting (amounts, quantities), `%editw` is used when the layout does not fit any of the predefined edit codes.


### %date / %diff / %days / %hours / %minutes / %months / %years

```
   dcl-s wOrderDte date(*iso);
   dcl-s wDueDte   date(*iso);
   dcl-s wDaysLeft int(5);

   wOrderDte = %date();                          // today's date
   wDueDte   = wOrderDte + %days(30);             // 30 days after the order date
   wDaysLeft = %diff(wDueDte:%date():*days);      // difference in days

   dsply wDaysLeft;
```

- `%date()` returns the current date. `%date(value)` converts a character, numeric or timestamp value into a date.
- `%days(n)` returns a duration of `n` days, used to add or subtract days from a date or timestamp. `%months(n)` and `%years(n)` do the same for months and years.
- `%hours(n)` and `%minutes(n)` do the same, for a time or timestamp.
- `%diff(value1:value2:unit)` returns the difference between two dates, times or timestamps, in the given unit (`*days`, `*months`, `*years`, `*hours`, `*minutes`, ...).

```
   dcl-s wStart timestamp inz(*sys);
   dcl-s wEnd   timestamp;

   wEnd = wStart + %hours(2) + %minutes(30);      // 2 hours and 30 minutes later

   dsply %diff(wEnd:wStart:*minutes);              // 150
```


## %elem / %min / %max

```
   dcl-s wMonth char(9) dim(12);
   dcl-s wA int(5) inz(10);
   dcl-s wB int(5) inz(25);

   dsply %elem(wMonth);          // 12, the number of elements in the array
   dsply %min(wA:wB);            // 10
   dsply %max(wA:wB);            // 25
```

- `%elem(array)` returns the number of elements of an array. Handy in a `for` loop, so the upper limit does not need to be hardcoded.

```
   dcl-s i int(5);

   for i = 1 to %elem(wMonth);
      dsply wMonth(i);
   endfor;
```

- `%min` and `%max` return the smallest, resp. largest, value of a list of values.


## %lookup

`%lookup` searches an array for a value, and returns the index of the first matching element, or `0` when nothing matches.

```
   dcl-s wMonth char(9) dim(12);
   dcl-s i      int(5);

   wMonth(1) = 'January';
   wMonth(2) = 'February';
   wMonth(3) = 'March';

   i = %lookup('February':wMonth);

   if i > 0;
      dsply i;                    // 2
   else;
      dsply 'not found';
   endif;
```

- `%lookup(value:array:start:num)` : `start` and `num` are optional, they limit the search to `num` elements starting at `start`, instead of the whole array.
- `%lookupge`, `%lookupgt`, `%lookuple` and `%lookuplt` search for the first element that is greater(-or-equal), resp. less(-or-equal), than `value`, instead of an exact match. These require the array to be declared `ascend` or `descend` (see the Arrays chapter).


## %parms / %parmnum

`%parms` returns the number of parameters that were actually passed to the current program or procedure. `%parmnum(parameter)` returns the position of a parameter in the parameter list. Both are typically used together with `options(*nopass)`, to check whether an optional parameter was passed.

```
   dcl-pi *n;
      pRtcd char(1);
      pAccd char(2);
      pData char(2000);
   end-pi;

   if %parms >= %parmnum(pAccd);
      dsply 'pAccd was passed';
   endif;
```


## Other useful built-in functions

```
   dcl-s wAmount packed(7:2);
   dcl-s wPtr    pointer;

   wPtr = %addr(wAmount);
   dsply %size(wAmount);          // number of bytes wAmount occupies
```

- `%addr(variable)` returns the address (a pointer) of a variable.
- `%size(variable)` returns the number of bytes a variable occupies in storage.
