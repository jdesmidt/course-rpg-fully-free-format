# Control statements

Control statements are used to define global compiler and runtime settings.

It must start with `ctl-opt` and end with a semi-colon.

Keywords can be written on a single or on multiple lines.

```
    ctl-opt copyright('Jürgen Desmidt');

    ctl-opt datfmt(*eur) timfmt(*hms);
    ctl-opt alwnull(*usrctl);

    ctl-opt option(*srcstmt : *nodebugio)
            bnddir('JDSRVPGM');

```

## Common CTL-OPT statements

### text

```
    ctl-opt text('Hello World - first program');
```

Sets the object description when creating the module or program.

### copyright

```
    ctl-opt copyright('Jürgen Desmidt');
```

Adds copyright information when creating the module or program.

### decedit

```
    ctl-opt decedit('0.');
```

Controls the formatting of decimal numbers. It allows you to define a decimal separator and specify whether a leading zero is printed during conversions and operations.

### datfmt and timfmt

```
    ctl-opt datfmt(*iso) timfmt(*iso);
```

Sets the standard YYYY-MM-DD and HH:MM:SS formats for all date and time fields unless explicitly overridden.

### alwnull

```
    ctl-opt alwnull(*usrctl);
```

This tells the compiler to allow you to manually handle database null values in the code.

### option

```
    ctl-opt option(*srcstmt : *nodebugio);
```

The option `*srcstmt` ensures when the program crashes, the line numbers in the dump match the line numbers of the source code (instead of the compiler listing.)

The option `*nodebugio` stops the debugger from pausing on hidden file operations (like READ or WRITE) and makes debugging faster.

### dftactgrp

```
    ctl-opt dftactgrp(*no) actgrp(*caller);
```

Ensures the program runs in the ILE (Integrated Language Environment) program rather than using the default OPM (Original Program Model) activation group. This is mandatory when using ILE API's, service programs and/or procedures.
