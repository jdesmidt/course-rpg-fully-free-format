# Selections and iterations

Selection and iteration statements control which statements are executed, and how many times, based on a condition.

### Comparison and logical operators

| Operator | Meaning |
| --- | --- |
| `=` | equal to |
| `<>` | not equal to |
| `>` / `<` | greater than / less than |
| `>=` / `<=` | greater than or equal to / less than or equal to |
| `and` / `or` | combine multiple conditions |
| `not` | negates a condition |

```
   if wAmount > 100 and wFound = *on;
```


## Selection statements

### if / else / endif

```
   if wAmount > 100;
      dsply 'Amount is high';
   else;
      dsply 'Amount is low';
   endif;
```

### if / elseif / else / endif

`elseif` allows to test multiple conditions in sequence. Only the first matching branch is executed.

```
   if wAmount > 1000;
      dsply 'Amount is very high';
   elseif wAmount > 100;
      dsply 'Amount is high';
   else;
      dsply 'Amount is low';
   endif;
```

### select / when / endsl

`select` is used when multiple values of the same field need to be compared. Only the first matching `when` is executed. `other` is optional and acts as a default when no `when` matches.

```
   select;
      when wAccd = '01';
         dsply 'New';
      when wAccd = '02';
         dsply 'Update';
      when wAccd = '04';
         dsply 'Delete';
      other;
         dsply 'Unknown action code';
   endsl;
```


## Iteration statements

### dow / enddo

`dow` (do while) checks the condition **before** each pass, so the loop body may not execute at all.

```
   dcl-s wCount int(5) inz(1);

   dow wCount <= 5;
      dsply wCount;
      wCount += 1;
   enddo;
```

### dou / enddo

`dou` (do until) checks the condition **after** each pass, so the loop body always executes at least once.

```
   dcl-s wCount int(5) inz(1);

   dou wCount > 5;
      dsply wCount;
      wCount += 1;
   enddo;
```

### for / endfor

`for` is used to repeat a block a known number of times, using a loop counter. The default step is 1, but a different step can be set with `by`.

```
   dcl-s i int(5);

   for i = 1 to 5;
      dsply i;
   endfor;

   for i = 10 downto 1 by 2;
      dsply i;
   endfor;
```

The `for` loop is also the natural way to walk through an array.

```
   dcl-s wMonth char(9) dim(12);
   dcl-s i      int(5);

   wMonth(1) = 'January';
   wMonth(2) = 'February';

   for i = 1 to 12;
      dsply wMonth(i);
   endfor;
```

`for-each` (see the Arrays chapter) is often simpler for this, it does not need a loop counter at all.

### leave and iter

`leave` immediately exits the current loop. `iter` immediately skips to the next iteration of the current loop.

```
   for i = 1 to 10;
      if i = 3;
         iter;                    // skip the rest of this pass, continue with i = 4
      endif;
      if i = 7;
         leave;                   // stop the loop entirely
      endif;
      dsply i;
   endfor;
```
